# Port Linux Python do Codenotch

Este diretório preserva o snapshot do port Python Linux v1.17.0 que estava em uso neste computador em 22/10/2026, incluindo as personalizações locais da interface, os glifos e os launchers `codenotch` e `codenotch-hook`.

O snapshot é independente do port Rust/Tauri mantido em `windows/`. Para instalar as dependências e executar esta versão no Ubuntu/Linux Mint, consulte o [guia Linux em português](../../docs/linux-installation-pt-BR.md#port-linux-atualmente-utilizado-python-1170).

Somente código e recursos necessários para a aplicação foram preservados. Configurações pessoais, credenciais, histórico, bancos de dados, caches e logs locais não fazem parte do repositório.
